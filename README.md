# nika-open/.github

This repository holds the profile of the Nika organization on GitHub
([`profile/README.md`](profile/README.md)) and the default community health files of its
repositories ([`SECURITY.md`](SECURITY.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)).

The banner and the avatar in [`profile/assets/`](profile/assets/) are drawn from the
[nika.sh brand kit](https://nika.sh/brand/): the butterfly mark, the site's color roles and its
Martian Grotesk and Martian Mono faces. [`profile/assets/SOURCE.md`](profile/assets/SOURCE.md)
records how they were rendered.
