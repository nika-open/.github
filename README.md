# nika-open/.github

This repository holds the profile of the Nika organization on GitHub
([`profile/README.md`](profile/README.md)) and the default community health files of its
repositories ([`SECURITY.md`](SECURITY.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)).

[`profile/assets/`](profile/assets/) holds the pictures of the profile and the banner each
repository README opens on. They are drawn in the style of [nika.sh](https://nika.sh): the
butterfly mark, the site's color roles in the dark and the light theme, and its faces. Every
animated picture has a still for readers who ask for reduced motion, and the profile has a
layout for narrow screens. [`profile/assets/SOURCE.md`](profile/assets/SOURCE.md) lists every
file and records how it was rendered.
